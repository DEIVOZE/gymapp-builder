# Установка APK на телефон

APK собирается автоматически в облаке (GitHub Actions) при каждом обновлении
ветки `main`. Готовый файл — во вкладке **Actions** → последняя зелёная сборка
→ раздел **Artifacts** → `GymLog-apk` (внутри zip лежит `GymLog.apk`).

## Первый раз

1. Перекинь `GymLog.apk` на телефон (Telegram «избранное», кабель, облако).
2. Открой файл на телефоне. Android спросит разрешение
   «устанавливать из неизвестных источников» — разреши для той программы,
   через которую открываешь.
3. Установи. Появится иконка штанги «Дневник тренировок».
4. Если данные были в браузерной версии: в ней ⚙️ → «Скачать копию (JSON)»,
   перекинь файл на телефон, в приложении ⚙️ → «Восстановить из файла».

## Обновление

1. Поменяй код → `git push` → дождись зелёной сборки (~5 мин).
2. Скачай новый `GymLog.apk`, поставь поверх старого.
   Подпись одна и та же (ключ `keystore.b64` лежит в репозитории),
   поэтому данные приложения сохраняются.

## Как устроена сборка (`.github/workflows/build-apk.yml`)

1. Устанавливает Node.js и Capacitor, генерирует нативный Android-проект.
2. Собирает release-версию Gradle'ом.
3. Подписывает её ключом `keystore.b64` (сгенерирован при первой сборке
   и закоммичен автоматически). Один и тот же ключ = обновления ставятся
   поверх без потери данных.
4. Кладёт `GymLog.apk` в артефакты сборки.

Пароль ключа подписи: `gymlog-secret-pass` (для личного приложения достаточно;
хранится прямо в рецепте сборки, сам ключ — в приватном репозитории).
