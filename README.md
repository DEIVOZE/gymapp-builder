# Дневник тренировок

Мобильное веб-приложение: календарь по дням, в каждом дне — упражнения,
у каждого упражнения — подходы (вес кг / повторения / RIR).

Возможности:
- упражнения выбираются из **выпадающего списка** ранее введённых, либо можно
  ввести своё название (пункт «➕ Другое упражнение…») — оно запомнится;
- у каждого поля подхода есть **стрелки ±**: кг шагает по 2.5, повторения
  и RIR — по 1; новый подход наследует значения предыдущего;
- **заметка к дню** (самочувствие, схема…) — попадает в экспорт;
- экспорт в текстовый файл **или сразу в буфер обмена**: день / месяц / период;
- страница **«Прогресс»** (📈 в шапке): сравнивает первую и последнюю тренировку
  каждого упражнения за период — вырос вес → показывает новый вес,
  вес тот же → сравнивает повторения;
- кнопка «⤵ Перейти к сегодняшнему дню» в календаре;
- резервная копия всех данных в JSON.

Работает офлайн, устанавливается на главный экран телефона как обычное
приложение (иконка, полный экран без адресной строки).

## Файлы проекта

| Файл | За что отвечает |
|---|---|
| `index.html` | Разметка: два экрана (календарь и день) и два всплывающих окна (экспорт, настройки). Смотри комментарии внутри. |
| `style.css` | Внешний вид. Цвета заданы переменными в самом верху (`--bg`, `--accent` и т.д.) — поменял переменную, поменялась вся тема. |
| `app.js` | Вся логика. Разделён на 8 пронумерованных разделов с подробными комментариями на русском. |
| `manifest.webmanifest` | Описывает приложение для установки на телефон: имя, иконки, цвета. |
| `sw.js` | Service worker — кэширует файлы, чтобы приложение работало офлайн. |
| `icons/` | Иконки (PNG сгенерированы скриптом `gen_icons.py`, там же можно перерисовать). |
| `gen_icons.py` | Скрипт на Python, который рисует иконки. Запуск: `py gen_icons.py`. |

## Как хранятся данные

Всё лежит в **localStorage браузера телефона** (ключ `gymlog_v1`) в виде одного
JSON-объекта:

```json
{
  "workouts": {
    "2026-10-26": {
      "note": "выспался, техника норм",
      "exercises": [
        {
          "name": "Жим лёжа",
          "sets": [ { "weight": 80, "reps": 8, "rir": 2 } ]
        }
      ]
    }
  },
  "exercises": ["Жим лёжа"]
}
```

- `workouts` — записи по дням, ключ = дата `'ГГГГ-ММ-ДД'`.
- `exercises` — список названий для выпадающего меню.
- `note` — заметка дня (может отсутствовать).

Посмотреть свои данные можно в настройках → «Скачать копию (JSON)».

## Установка на телефон

Приложению нужен любой https-хостинг (или локальный сервер). Самый простой
способ — **GitHub Pages**, бесплатно:

1. Заведи аккаунт на github.com, создай репозиторий (например, `gymapp`).
2. Загрузи туда все файлы проекта (через веб-интерфейс — кнопка *Add file → Upload files*).
3. В репозитории: *Settings → Pages → Source: Deploy from a branch → main → Save*.
4. Через минуту адрес вида `https://твой-логин.github.io/gymapp/` заработает.
5. Открой его в Chrome на телефоне → меню ⋮ → **«Добавить на главный экран» / «Установить приложение»**. Появится иконка, приложение открывается на весь экран и работает офлайн.

### Альтернатива: посмотреть дома без хостинга

На компьютере в папке проекта запусти:

```
py -m http.server 8765
```

и открой `http://localhost:8765` в браузере. Телефон в той же Wi-Fi сети
сможет открыть `http://IP-компьютера:8765`, но установка иконки там менее
надёжна (Chrome любит https) — для постоянного использования лучше GitHub Pages.

### Можно ли вообще без сервера?

Да: скинь `index.html`, `style.css`, `app.js` на телефон и открой `index.html`.
Приложение будет работать (данные сохраняются), но не будет иконки на главном
экране и офлайн-кэша.

## Как это менять (шпаргалка)

**Поменять цвета** — переменные в начале `style.css`.

**Поменять формат экспорта** — функция `buildExportText()` в `app.js`:
она собирает список строк и склеивает их в текст файла.

**Поменять поведение кнопок** — все обработчики собраны в одном месте,
функция `bindEvents()` в конце `app.js`.

**Поменять логику прогресса** — раздел 7 в `app.js`: `bestSet()` выбирает
лучший подход (максимальный вес, при равном — больше повторений),
`renderProgress()` сравнивает первую и последнюю тренировку упражнения.
Шаги стрелок ± задаются константой `SET_FIELDS` в разделе 4.

**Что-то сломалось после правки** — открой приложение в браузере компьютера,
нажми `F12` → вкладка *Console*: там будет красная строка с ошибкой и номером
строки в файле.

**Важно после изменения файлов** (когда приложение уже стоит на телефоне):
увеличь версию кэша в `sw.js`, первая строка:

```js
const CACHE = 'gymlog-v1';  //  →  'gymlog-v2'
```

Иначе телефон продолжит показывать старую копию из офлайн-кэша.

## Экспорт TXT

Кнопка 📤 на календаре: экспорт дня / месяца / произвольного периода.
Кнопка 📤 на экране дня: сразу экспорт этого дня. В модалке два действия:
«⬇ .txt» — скачать файл, «📋 В буфер» — скопировать тот же текст в буфер
обмена (удобно вставить в заметки или чат). Пример результата:

```
ОТЧЁТ ПО ТРЕНИРОВКАМ

Период: 26.10.2026 — 26.10.2026

═══ 26 октября 2026, понедельник ═══
📝 заметка дня (если есть)
Жим лёжа:
   1. 80 кг × 8 (RIR 2)
   2. 82.5 кг × 6 (RIR 1)
   Итого подходов: 2

─────────────────────
Тренировок: 1, всего подходов: 2
```

## Резервная копия

⚙️ → «Скачать копию (JSON)» — файл со всеми данными.
На новом телефоне: ⚙️ → «Восстановить из файла». Делай копию время от
времени: данные живут в браузере, и если очистить данные сайта — они пропадут.
